# Связь — найди свой вайб

Сайт знакомств на Laravel 12, React 19 и SQLite. На главной — движущаяся стена фотографий, смена фраз, мемный пёс и интерактивные примеры анкет под разный вайб. Розовый, оранжевый и синий продолжают исходный дизайн. Анимации можно остановить; системная настройка reduced motion учитывается автоматически.

Главная страница `/` открывается первой, в том числе для уже вошедших пользователей. Отдельный личный кабинет доступен по `/cabinet` после входа. Регистрация, обычный вход и демовход переводят в кабинет. Логотип кабинета возвращает на главную.

## Запуск

Папка проекта: `C:\Users\timur\Desktop\Dating`.

В PowerShell 7:

```powershell
.\START.ps1
```

Откройте http://127.0.0.1:8000. Если сервер уже запущен, достаточно открыть адрес.

Окружение разработки: PHP 8.5, Composer 2, Node.js. Текущий lock-файл требует PHP 8.4 или новее. Нужны PDO SQLite, mbstring, fileinfo, openssl, curl, xml и zip.

Скрипт устанавливает недостающие зависимости, создаёт `.env`, готовит `database/svyaz.sqlite`, выполняет миграции и добавляет демонстрационные анкеты. Повторный запуск сохраняет пользовательские данные. Seeder обновляет только шесть демонстрационных анкет.

Исходная база `database/database.sqlite` сохранена без изменений. Дополнительная копия: `database/database.original.sqlite`. Приложение использует отдельную базу `svyaz.sqlite`.

## Возможности

- Регистрация по email и паролю. Сервер проверяет возраст от 18 лет, подтверждение пароля и согласие на хранение данных.
- Сессионный вход и выход, хеширование паролей, защита CSRF, ограничение частоты запросов.
- Личный кабинет: имя, город, описание, цель знакомства, предпочтения, до десяти интересов.
- До шести фотографий JPG, PNG или WebP, до 5 МБ каждая. Удаление собственных фото.
- Анкеты по одной: лайк, пропуск, возврат пропуска, стрелки клавиатуры и перетаскивание.
- Фильтры по полу, возрасту, городу и цели знакомства.
- Входящие симпатии и совпадения. Взаимный лайк открывает чат.
- Сообщения хранятся в базе. Открытый чат обновляется каждые шесть секунд.
- Скрытие анкеты, двусторонняя блокировка, сохранение жалоб.
- Удаление аккаунта с проверкой пароля и удалением связанных данных и загруженных фото.
- Адаптивная верстка, навигация для телефона, фокус в диалогах, поддержка reduced motion.

## Демонстрация

Нажмите «Войти», затем «Посмотреть демо без регистрации». Создаётся отдельная сессия с собственной анкетой. Три демонстрационные анкеты уже поставили ей лайк: ответный лайк показывает совпадение и открывает переписку.

Демособеседники не отправляют автоматических ответов. Их статус указан в подробной анкете и чате. Для проверки переписки между людьми зарегистрируйте два аккаунта в разных браузерах и поставьте взаимные лайки.

Демовход доступен при `APP_ENV=local` или `testing`. Гости видят только демонстрационные анкеты. Реальные анкеты доступны авторизованным пользователям.

## Размещение

Нужен хостинг с PHP 8.4+ и корнем сайта `public/`. Sites/Cloudflare Workers не запускает PHP backend.

На сервере задайте собственные `APP_KEY`, `APP_URL`, параметры БД, `APP_ENV=production`, `APP_DEBUG=false`, `SESSION_SECURE_COOKIE=true`. Выполните `composer install --no-dev --optimize-autoloader`, `npm ci`, `npm run build`, `php artisan migrate --force`, `php artisan storage:link`. Каталоги `storage` и `bootstrap/cache` должны быть доступны для записи. PHP development server предназначен для локальной разработки.

В этой версии нет отправки писем, восстановления пароля, WebSocket-сервера, платежей, автоматической проверки фото или панели модератора. Жалобы сохраняются в таблице `reports`. Документы сервиса и процесс модерации нужно подготовить перед публичным запуском.
